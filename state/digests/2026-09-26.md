## 1. Find Latest Group of Size M

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/find-latest-group-of-size-m/

### Problem

You're given a permutation `arr` of `1..n`. Starting from an all-zero binary string of length `n`, at step `i` you flip the bit at position `arr[i]` to `1` (1-indexed). Find the **latest** step at which there exists a maximal contiguous group of `1`s of length exactly `m`. Return `-1` if that never happens.

**Examples**
- `arr = [3,5,1,2,4], m = 1` → `4`
- `arr = [3,1,5,4,2], m = 2` → `-1`

**Constraints:** `1 <= m <= n <= 10^5`, all `arr[i]` distinct.

### Intuition

Simulating the string directly and rescanning for groups at every step is `O(n^2)`. Instead, notice that when we set a new bit, it can only merge with its **immediate left and right neighbors' groups** (since everything else is untouched). So we only need to know the length of the group immediately to the left and immediately to the right of the new bit — we don't need to know anything about groups further away.

Trick: keep a `length[]` array where `length[p]` is only meaningful (and correct) at the two **endpoints** of a group — `length[start] == length[end] == group_length`. When we set bit `pos`, we look up `length[pos-1]` (left neighbor's group length, 0 if it's not set) and `length[pos+1]` (right neighbor's group length), merge them into one group of size `left + right + 1`, and write that new length at the *new* endpoints of the merged group.

The subtle part is catching the "latest step with a group of size `m`" without rescanning. A group of size `m` can only stop existing at the moment it gets swallowed by a merge — either as the `left` piece or the `right` piece of a new merge. So every time we perform a merge, if `left == m` or `right == m`, that means **right before this step**, a group of size `m` existed. So the answer, if it exists, is `step - 1` at that point (keep overwriting `ans` — the last time this happens is the true answer).

One edge case: if `m == n`, the group of size `m` is the *final* fully-filled string, which never gets destroyed by a merge (there's nothing left to merge into). Handle that separately: the answer is simply `n`.

### Step-by-step walkthrough

1. If `m == n`, return `n` immediately (final full string is the only way to get a size-`n` group, and it's never destroyed).
2. Create `length = [0] * (n + 2)` (padded so `pos-1`/`pos+1` never go out of bounds) and `ans = -1`.
3. For `step` from `1` to `n`, with `pos = arr[step-1]`:
   - `left = length[pos-1]`, `right = length[pos+1]`.
   - `new_len = left + right + 1`.
   - Write `new_len` at both new endpoints: `length[pos - left] = new_len` and `length[pos + right] = new_len`.
   - If `left == m` or `right == m`, set `ans = step - 1`.
4. Return `ans`.

Trace `arr=[3,5,1,2,4], m=1`:
- step1 pos=3: left=0,right=0 → group `[3,3]` len 1. no match.
- step2 pos=5: left=0,right=0 → group `[5,5]` len 1. no match.
- step3 pos=1: left=0,right=0 → group `[1,1]` len 1. no match.
- step4 pos=2: left=length[1]=1, right=length[3]=1 → merges into len 3 `[1,3]`. `left==1` → `ans = 3`.
- step5 pos=4: left=length[3]=3, right=length[5]=1 → merges into len 5 `[1,5]`. `right==1` → `ans = 4`.
- Final `ans = 4` ✓.

### Complexity

- **Time:** O(n) — one pass over `arr`, O(1) work per step.
- **Space:** O(n) for the `length` array.

### Python Solution

```python
from typing import List


class Solution:
    def findLatestStep(self, arr: List[int], m: int) -> int:
        n = len(arr)
        if m == n:
            return n

        length = [0] * (n + 2)
        ans = -1

        for step, pos in enumerate(arr, 1):
            left = length[pos - 1]
            right = length[pos + 1]
            new_len = left + right + 1
            length[pos - left] = new_len
            length[pos + right] = new_len
            if left == m or right == m:
                ans = step - 1

        return ans


if __name__ == "__main__":
    sol = Solution()
    print(sol.findLatestStep([3, 5, 1, 2, 4], 1))  # 4
    print(sol.findLatestStep([3, 1, 5, 4, 2], 2))  # -1
```

## 2. Form Smallest Number From Two Digit Arrays

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/form-smallest-number-from-two-digit-arrays/

### Problem

Given two arrays `nums1` and `nums2` of unique digits, return the smallest number that contains **at least one** digit from each array (a digit that appears in both arrays satisfies both requirements at once).

**Examples**
- `nums1 = [4,1,3], nums2 = [5,7]` → `15`
- `nums1 = [3,5,2,6], nums2 = [3,1,7]` → `3`

**Constraints:** `1 <= nums1.length, nums2.length <= 9`, all digits `1..9`, unique within each array.

### Intuition

Two cases:
1. **A shared digit exists.** Then a single digit from that intersection satisfies "at least one from each array" trivially, and a 1-digit number is always smaller than any 2-digit number. Among shared digits, pick the smallest one.
2. **No shared digit.** Then the answer must be a 2-digit number: one digit from `nums1`, one from `nums2`. To minimize the 2-digit number, take the smallest digit from each array, and put the smaller of those two digits first (as the tens place).

### Step-by-step walkthrough

1. Compute `common = set(nums1) & set(nums2)`.
2. If `common` is non-empty, return `min(common)`.
3. Otherwise, let `a = min(nums1)`, `b = min(nums2)`.
4. Return `min(a, b) * 10 + max(a, b)` (smaller digit in front minimizes the number).

Trace `nums1=[4,1,3], nums2=[5,7]`: no common digits. `a=1, b=5`. Result `1*10+5=15` ✓.

Trace `nums1=[3,5,2,6], nums2=[3,1,7]`: common = `{3}`. Result `3` ✓.

### Complexity

- **Time:** O(n + m) for building sets and scanning for minimums.
- **Space:** O(n + m) for the sets.

### Python Solution

```python
from typing import List


class Solution:
    def minNumber(self, nums1: List[int], nums2: List[int]) -> int:
        common = set(nums1) & set(nums2)
        if common:
            return min(common)

        a, b = min(nums1), min(nums2)
        return min(a, b) * 10 + max(a, b)


if __name__ == "__main__":
    sol = Solution()
    print(sol.minNumber([4, 1, 3], [5, 7]))       # 15
    print(sol.minNumber([3, 5, 2, 6], [3, 1, 7]))  # 3
```

## 3. Check if Matrix Is X-Matrix

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/check-if-matrix-is-x-matrix/

### Problem

A square matrix is an **X-Matrix** if every element on either diagonal (main or anti-diagonal) is non-zero, and every other element is zero. Given an `n x n` grid, return whether it's an X-Matrix.

**Examples**
- `grid = [[2,0,0,1],[0,3,1,0],[0,5,2,0],[4,0,0,2]]` → `true`
- `grid = [[5,7,0],[0,3,1],[0,5,0]]` → `false`

**Constraints:** `3 <= n <= 100`, `0 <= grid[i][j] <= 10^5`.

### Intuition

For any cell `(i, j)` in an `n x n` grid, it lies on the main diagonal when `i == j`, and on the anti-diagonal when `i + j == n - 1`. So we just walk every cell once and check the rule directly: on a diagonal → must be non-zero; off both diagonals → must be zero. Any violation means it's not an X-Matrix.

### Step-by-step walkthrough

1. For each `i` in `range(n)`, for each `j` in `range(n)`:
   - If `i == j or i + j == n - 1`: fail if `grid[i][j] == 0`.
   - Else: fail if `grid[i][j] != 0`.
2. If no violation was found after scanning everything, return `True`.

Trace on example 2 (`n=3`): cell `(0,2)` is on the anti-diagonal (`0+2==2==n-1`) but `grid[0][2]==0` → violation → `False` ✓.

### Complexity

- **Time:** O(n²) — must inspect every cell.
- **Space:** O(1) extra.

### Python Solution

```python
from typing import List


class Solution:
    def checkXMatrix(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        for i in range(n):
            for j in range(n):
                on_diagonal = (i == j) or (i + j == n - 1)
                if on_diagonal and grid[i][j] == 0:
                    return False
                if not on_diagonal and grid[i][j] != 0:
                    return False
        return True


if __name__ == "__main__":
    sol = Solution()
    print(sol.checkXMatrix([[2, 0, 0, 1], [0, 3, 1, 0], [0, 5, 2, 0], [4, 0, 0, 2]]))  # True
    print(sol.checkXMatrix([[5, 7, 0], [0, 3, 1], [0, 5, 0]]))  # False
```

## 4. Length of the Longest Alphabetical Continuous Substring

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/length-of-the-longest-alphabetical-continuous-substring/

### Problem

An "alphabetical continuous string" is any substring of `"abcdefghijklmnopqrstuvwxyz"` (i.e., consecutive letters, like `"cde"`). Given a lowercase string `s`, return the length of the longest such substring found in `s`.

**Examples**
- `s = "abacaba"` → `2` (`"ab"`)
- `s = "abcde"` → `5` (the whole string)

**Constraints:** `1 <= s.length <= 10^5`.

### Intuition

This is just a sliding-window / running-streak problem: walk through the string once, and keep extending a running streak as long as each character is exactly one letter after the previous one (`ord(s[i]) == ord(s[i-1]) + 1`). The moment that breaks, reset the streak to `1` (the current character starts a fresh streak). Track the maximum streak length seen.

### Step-by-step walkthrough

1. Initialize `longest = cur = 1`.
2. For `i` from `1` to `len(s) - 1`:
   - If `ord(s[i]) == ord(s[i-1]) + 1`: extend, `cur += 1`.
   - Else: reset, `cur = 1`.
   - Update `longest = max(longest, cur)`.
3. Return `longest`.

Trace `s = "abacaba"`: streaks are `a`(1), `ab`(2, since b=a+1) → reset at `a`(1, break) → `ac`? `c` after `a` is not `a+1` so reset to 1 → `a`(1) → `ab`(2) → `a`(1). Max streak = 2 ✓.

### Complexity

- **Time:** O(n) — single pass.
- **Space:** O(1).

### Python Solution

```python
class Solution:
    def longestContinuousSubstring(self, s: str) -> int:
        longest = cur = 1
        for i in range(1, len(s)):
            if ord(s[i]) == ord(s[i - 1]) + 1:
                cur += 1
            else:
                cur = 1
            longest = max(longest, cur)
        return longest


if __name__ == "__main__":
    sol = Solution()
    print(sol.longestContinuousSubstring("abacaba"))  # 2
    print(sol.longestContinuousSubstring("abcde"))    # 5
```

## 5. Sorting Three Groups

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/sorting-three-groups/

### Problem

You have an array `nums` where every element is `1`, `2`, or `3`. In one operation you can remove one element. Return the minimum number of removals needed to make `nums` non-decreasing.

**Examples**
- `nums = [2,1,3,2,1]` → `3`
- `nums = [1,3,2,1,3,3]` → `2`
- `nums = [2,2,2,2,3,3]` → `0`

**Constraints:** `1 <= nums.length <= 100`, `1 <= nums[i] <= 3`.

### Intuition

Minimizing removals to make an array non-decreasing is the same problem as *maximizing* the length of a subsequence that's already non-decreasing (keep that subsequence, remove everything else). So the answer is `n - (length of longest non-decreasing subsequence)`.

Normally computing the longest non-decreasing subsequence is `O(n log n)` with a general array, but here values are restricted to just `{1, 2, 3}`. That means we only need to track **3 running values**: the length of the best non-decreasing subsequence ending in `1`, ending in `2`, and ending in `3`, updating them as we scan left to right.

### Step-by-step walkthrough

1. Initialize `dp1 = dp2 = dp3 = 0` (best subsequence length ending in value `1`, `2`, `3` respectively, using elements seen so far).
2. For each `num` in `nums`:
   - If `num == 1`: `dp1 = dp1 + 1` (only extends subsequences that also end in `1`, since it must stay non-decreasing).
   - If `num == 2`: `dp2 = max(dp1, dp2) + 1` (can extend a subsequence ending in `1` or `2`).
   - If `num == 3`: `dp3 = max(dp1, dp2, dp3) + 1` (can extend a subsequence ending in `1`, `2`, or `3`).
3. The longest non-decreasing subsequence length is `max(dp1, dp2, dp3)`.
4. Return `len(nums) - max(dp1, dp2, dp3)`.

Trace `nums = [2,1,3,2,1]`:
- `2`: dp2 = max(0,0)+1 = 1 → (0,1,0)
- `1`: dp1 = 0+1 = 1 → (1,1,0)
- `3`: dp3 = max(1,1,0)+1 = 2 → (1,1,2)
- `2`: dp2 = max(1,1)+1 = 2 → (1,2,2)
- `1`: dp1 = 1+1 = 2 → (2,2,2)
- max = 2, `n=5` → answer `5-2=3` ✓.

### Complexity

- **Time:** O(n) — single pass, constant work per element.
- **Space:** O(1) — just three counters.

### Python Solution

```python
from typing import List


class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        dp1 = dp2 = dp3 = 0
        for num in nums:
            if num == 1:
                dp1 = dp1 + 1
            elif num == 2:
                dp2 = max(dp1, dp2) + 1
            else:
                dp3 = max(dp1, dp2, dp3) + 1
        return len(nums) - max(dp1, dp2, dp3)


if __name__ == "__main__":
    sol = Solution()
    print(sol.minimumOperations([2, 1, 3, 2, 1]))       # 3
    print(sol.minimumOperations([1, 3, 2, 1, 3, 3]))    # 2
    print(sol.minimumOperations([2, 2, 2, 2, 3, 3]))    # 0
```

## 6. Most Profit Assigning Work

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/most-profit-assigning-work/

### Problem

There are `n` jobs, each with a `difficulty[i]` and `profit[i]`, and `m` workers each with an ability `worker[i]`. A worker can do any job whose difficulty is `<=` their ability (at most one job each, but a job can be reused by multiple workers). Return the maximum total profit achievable.

**Examples**
- `difficulty=[2,4,6,8,10], profit=[10,20,30,40,50], worker=[4,5,6,7]` → `100`
- `difficulty=[85,47,57], profit=[24,66,99], worker=[40,25,25]` → `0`

**Constraints:** `1 <= n, m <= 10^4`, values up to `10^5`.

### Intuition

A worker with a given ability should always take the **most profitable job they can possibly qualify for**, not necessarily the hardest one. Since a job can be reused, the effective "best profit available at ability level X" is a running maximum over all jobs with difficulty `<= X`.

So: sort jobs by difficulty, sort workers by ability, and sweep both with two pointers. As the worker ability threshold increases, add any newly-eligible job into a running "best profit so far" tracker. Each worker then just gets `best_profit_so_far` for their ability level.

### Step-by-step walkthrough

1. Pair up jobs as `(difficulty, profit)` and sort by difficulty.
2. Sort `worker` ascending.
3. Initialize `i = 0` (job pointer), `best = 0` (best profit unlocked so far), `total = 0`.
4. For each `w` in sorted `worker`:
   - While there are more jobs and `jobs[i].difficulty <= w`: update `best = max(best, jobs[i].profit)`, advance `i`.
   - Add `best` to `total` (this worker takes the best job they qualify for).
5. Return `total`.

Trace example 1: jobs sorted by difficulty: `(2,10),(4,20),(6,30),(8,40),(10,50)`. Workers sorted: `[4,5,6,7]`.
- `w=4`: unlock difficulty `<=4`: `(2,10)`,`(4,20)` → best=20. total=20.
- `w=5`: no new unlocks (`next diff=6>5`). total+=20=40.
- `w=6`: unlock `(6,30)` → best=30. total+=30=70.
- `w=7`: no new unlocks (`next diff=8>7`). total+=30=100.
- Final total = 100 ✓.

### Complexity

- **Time:** O(n log n + m log m) for the two sorts, then O(n + m) for the sweep.
- **Space:** O(n) for the sorted job pairs.

### Python Solution

```python
from typing import List


class Solution:
    def maxProfitAssignment(
        self, difficulty: List[int], profit: List[int], worker: List[int]
    ) -> int:
        jobs = sorted(zip(difficulty, profit))
        worker = sorted(worker)

        i = 0
        best = 0
        total = 0
        n = len(jobs)

        for w in worker:
            while i < n and jobs[i][0] <= w:
                best = max(best, jobs[i][1])
                i += 1
            total += best

        return total


if __name__ == "__main__":
    sol = Solution()
    print(sol.maxProfitAssignment([2, 4, 6, 8, 10], [10, 20, 30, 40, 50], [4, 5, 6, 7]))  # 100
    print(sol.maxProfitAssignment([85, 47, 57], [24, 66, 99], [40, 25, 25]))  # 0
```

## 7. Find Users With Valid E-Mails

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/find-users-with-valid-e-mails/

### Problem

Table `Users(user_id, name, mail)`. Find all users with a **valid** e-mail. A valid e-mail:
- Has a prefix name that starts with a **letter**, followed by any number of letters, digits, underscores (`_`), periods (`.`), or dashes (`-`).
- Has the domain `@leetcode.com` exactly.

**Example**

| user_id | name      | mail                       | valid? |
|---------|-----------|----------------------------|--------|
| 1       | Winston   | winston@leetcode.com       | ✅ |
| 2       | Jonathan  | jonathanisgreat             | ❌ no domain |
| 3       | Annabelle | bella-@leetcode.com        | ✅ (dash allowed) |
| 4       | Sally     | sally.come@leetcode.com    | ✅ (period allowed) |
| 5       | Marwan    | quarz#2020@leetcode.com    | ❌ `#` not allowed |
| 6       | David     | david69@gmail.com          | ❌ wrong domain |
| 7       | Shapiro   | .shapo@leetcode.com        | ❌ starts with `.` |

### Intuition

This is a database problem, but LeetCode's Pandas track (and this write-up) solves it as ordinary Python: build a regex that encodes the exact rule ("starts with a letter, then letters/digits/`_`/`.`/`-`, then exactly `@leetcode.com`"), and filter the rows whose `mail` fully matches it.

Regex: `^[A-Za-z][A-Za-z0-9_.-]*@leetcode\.com$`
- `^[A-Za-z]` — must start with exactly one letter.
- `[A-Za-z0-9_.-]*` — zero or more letters/digits/underscore/period/dash after that.
- `@leetcode\.com$` — must end with the literal domain (escaped dot, anchored to end of string so `@leetcode.com.evil.com` wouldn't sneak through).

The equivalent SQL (for reference, since the underlying problem is a SQL problem):
```sql
SELECT user_id, name, mail
FROM Users
WHERE mail REGEXP '^[A-Za-z][A-Za-z0-9_.-]*@leetcode\\.com$';
```

### Step-by-step walkthrough

1. Compile the pattern above.
2. For each row, test whether `mail` matches the pattern from start to end (`re.fullmatch`, or pandas' `str.match` which anchors at the start and we anchor the end ourselves with `$`).
3. Keep only the rows that match.

Trace: `jonathanisgreat` fails immediately (no `@`). `.shapo@leetcode.com` fails the `^[A-Za-z]` requirement (starts with `.`). `quarz#2020@leetcode.com` fails because `#` isn't in the allowed character class. `david69@gmail.com` fails because the domain isn't `leetcode.com`. The rest pass.

### Complexity

- **Time:** O(n · k) where `n` is the number of rows and `k` is average e-mail length (regex matching is linear in string length).
- **Space:** O(n) for the filtered result.

### Python Solution

```python
import re
import pandas as pd


EMAIL_PATTERN = re.compile(r"^[A-Za-z][A-Za-z0-9_.-]*@leetcode\.com$")


def valid_emails(users: pd.DataFrame) -> pd.DataFrame:
    mask = users["mail"].apply(lambda mail: bool(EMAIL_PATTERN.fullmatch(mail)))
    return users[mask][["user_id", "name", "mail"]]


if __name__ == "__main__":
    data = pd.DataFrame(
        {
            "user_id": [1, 2, 3, 4, 5, 6, 7],
            "name": ["Winston", "Jonathan", "Annabelle", "Sally", "Marwan", "David", "Shapiro"],
            "mail": [
                "winston@leetcode.com",
                "jonathanisgreat",
                "bella-@leetcode.com",
                "sally.come@leetcode.com",
                "quarz#2020@leetcode.com",
                "david69@gmail.com",
                ".shapo@leetcode.com",
            ],
        }
    )
    print(valid_emails(data))
    # Expected user_ids: 1, 3, 4
```
